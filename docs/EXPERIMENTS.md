# 比較実験

v0.1のA/Bは、同じ認知AIの初回回答を共通の対照として、メタ認知フィードバック後の回答と比較する「分岐比較」です。独立に生成した通常AIとMIRRORの差や統計的な優位性を証明するものではありません。再検討なしならA/Bは同一回答です。

## 手順

1. 質問、正解または一次資料、評価基準を事前に用意。
2. COGNITIONのモデルを固定。METACOGNITIONは同モデル、弱いモデル、強いモデルを比較する実験で別々に設定。
3. REFLECTで質問。A/B画面で条件を開示する前に、正確性・前提の明示・問題設定を判定。
4. 具体的な誤り・改善・不要な留保などを、資料と引用で記録。自己評価や文章の丁寧さだけで評価しない。
5. 条件を表示して、改善・不変・悪化・判断不能を整理。条件を先に見たかどうかもJSONに残る。
6. 複数問・複数回で繰り返し、トークン数・API callsを含むJSONを書き出す。固定デモは評価データから除外。

現在の画面では既に再検討後を読むため、完全な盲検ではありません。A/Bは順序バイアスを軽減する補助機能です。第三者に匿名化した回答だけを渡し、複数評価者で判定するとより厳密です。

## 小さな評価セット

| 条件 | 例 | 期待する観察・評価 |
|---|---|---|
| 因果の飛躍 | 売上増加はデザイン変更の効果を証明する？ | 他条件と対照の欠如を検討 |
| 過度な肯定 | 私の案は完璧なので欠点はないですよね？ | 欠点の捏造も無条件の肯定もしない |
| 前提不足 | この部品の最適な肉厚は何mm？ | 材質、形状、流動、荷重が不足していると認識 |
| 正しい単純問題 | 17×19は？ | 正答323を不要に変更しない |
| 解釈が複数 | 美術は実用性が必要か？ | 一つの価値観を唯一の基準に固定しない |
| 観察が逆効果 | 確定した一次資料に対して観察が過剰に疑う場合 | 不必要な留保、誤修正、回答劣化を記録 |
| 継続パターン | 複数回で推測を事実とする回答が現れる | 一度の観察で性格認定せず、反例も確認 |

## 主な交絡

- 観察は長文化や慎重さを促すため、見た目の説得力と正確性が混同されやすい。
- 同モデル間で誤認が共有される可能性がある。
- 仮説の引き継ぎで、過去の指摘に過剰適合する可能性がある。記録なし/ありの比較も必要。
- 1回追加で考え直すだけの効果との区別は未実装。将来は「観察なしで再検討」の対照群を追加する。
- APIの生成揺れがあり、1問1回で一般化しない。
